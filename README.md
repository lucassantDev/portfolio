## Sobre o projeto

Este portfólio foi desenvolvido para apresentar meus projetos, habilidades e trajetória como desenvolvedor frontend. O objetivo principal foi criar uma interface moderna, responsiva e visualmente agradável, aplicando conceitos de React, rotas, componentização e manipulação de estado.

## Tecnologias utilizadas

- React
- Vite
- JavaScript
- CSS
- Tailwind CSS
- React Router DOM
- Lucide React
- React Icons
- Motion
- ESLint
- shadcn/ui

## Como executar

```bash
npm install
npm run dev
```

A aplicação estará disponível no navegador em um endereço local gerado pelo Vite, normalmente em:

```bash
http://localhost:5173
```
